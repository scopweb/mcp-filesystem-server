## What is this?

An MCP server that gives Claude Desktop (and other MCP clients) safe, validated access to your local filesystem. 18 tools + 3 official MCP aliases covering file operations, search, analysis, batch changes, media reads, and development observability.

Built as the lightweight edition of [mcp-filesystem-go-ultra](https://github.com/scopweb/mcp-filesystem-go-ultra). Same normalizer layer that prevents parameter mismatches — without the full feature set.

<CardGrid>
  <Card title="18 Tools + 3 Aliases" icon="pencil">

  </Card>
  <Card title="Normalizer" icon="setting">
